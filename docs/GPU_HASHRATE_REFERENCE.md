## 6. 添加新 GPU 型号

需要修改 3 个文件：

1. **`manager/vast.py`** — `GPU_HASHRATES` 字典添加 `{normalized_key}: <th_s>`
2. **`electron-app/gpu.js`** — `getMinThreshold()` 添加匹配规则 + `powerMap` 添加 TDP
3. **`electron-app/state/config.json`** — 添加 `"min_th_{model}": <value>`（≈ 参考算力 × 0.7）

归一化 key 规则：小写 + 下划线，如 `rtx_5090`、`rtx_4080_super`、`h100`、`l40s`。
